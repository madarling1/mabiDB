개인정보처리방침

마비디비는 마비노기 모바일 정보를 검색하기 위한 비공식 DB 앱입니다.

1. 수집하는 정보

앱은 기본 검색 기능 사용 시 회원가입, 로그인, 위치 정보, 연락처, 결제 정보, 광고 식별자를 수집하지 않습니다.

사용자가 앱 내 “정보 수정 요청 / 건의 사항” 기능을 사용할 경우 다음 정보가 함께 전송될 수 있습니다.

  • 사용자가 입력한 제보 내용
  • 검색 범위
  • 검색어
  • 최근 검색 결과 일부
  • 앱 버전
  • DB 버전
  • 기기 제조사 및 모델명
  • Android SDK 버전
  • 서버 접속 과정에서 기록되는 IP 주소

2. 수집 목적

수집된 정보는 DB 정보 수정, 오류 확인, 제보 처리, 앱 품질 개선 목적으로만 사용됩니다.

3. 제3자 제공

수집된 정보는 앱 운영자가 제보 내용을 확인하기 위해 사용하는 서버로 전송될 수 있습니다. 광고, 마케팅, 판매 목적으로 제3자에게 제공하지 않습니다.

4. 보관 기간

제보 내용과 관련 로그는 앱 개선 및 오류 확인에 필요한 기간 동안 보관될 수 있으며, 목적 달성 후 즉시 삭제됩니다.

5. 앱 권한

앱은 인터넷 연결 권한을 사용합니다. 이 권한은 DB 업데이트 확인, 데이터 다운로드, 정보 수정 요청 전송에 사용됩니다.

6. 아동 개인정보

이 앱은 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
