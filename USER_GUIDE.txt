# 사용 설명서!

1. mabiDB.exe를 실행합니다.

2. 검색 범위를 선택합니다. 원하는 그룹의 숫자만 입력하면 됩니다.
   - 1: 무기 / 방어구 / 엠블럼 룬
   - 2: 장신구 룬
   - 3: 생활 채집물
   - 4: 물물 교환
   - 5: 제작법
   - 6: 데코 제작법

3. 원하는 검색어를 입력합니다. 

4. 검색 결과 화면에서 0을 입력하면 개발자에게 수정 요청을 보낼 수 있습니다.
   - 가능한 한 빠르게 확인하여 수정 후 답변을 보내드립니다.

5. 시작 화면의 내 수정 요청 답변 카드에서 문의/답변 내역을 확인할 수 있습니다.
-------------------------------------------------

# 초성 검색을 지원해요
   ㅇㄷㅎㅂ > 아득한빛

# 영타 검색을 지원해요
   dkemr > 아득

# 룬의 경우 태그 검색을 지원해요 (ex : 치명타, 피증, 공증, 직피 등등)


## 앱 및 데이터 업데이트
프로그램 실행 시 서버의 최신 앱 버전과 DB 버전을 확인합니다.
새 버전이 있으면 자동으로 업데이트해서 교체합니다.

## 주의 사항
관리자 권한이 필요한 시스템 폴더에 넣으면 사용이 불가 할 수 있습니다.
(다운로드 폴더 or 바탕화면 추천)
